# PIXEL PADDOCK 🐎🎮

実際の手元の `.keiba` を読み込んで馬ごとのステータス・比較・仮想レースを表示する、無料の静的Webアプリです。

## 公開URL

https://sobiito24-a11y.github.io/pixel-paddock/

## 使い方

1. サイトを開き、**「📂 .keiba ファイルを選択」** をタップ。
2. iPhoneなら「ファイル」から `.keiba` を選ぶ。選択画面では拡張子フィルターを付けていません。
3. 読込成功後に、日付・競馬場・レースから馬を選べます。
4. 馬のステータス・脚質別ドット絵、3頭比較、推し馬、横画面の仮想レースが利用できます。

**サンプルデータは一切収録していません。** 初回は0レース・0頭で、読み込み前はデータ選択・比較・レース部分を表示しません。「馬の図鑑」の初心者向け説明や紹介ページも削除し、実データ用の画面だけに整理しています。

## `.keiba` 読み込み仕様

- `.keiba` はZIPベースの専用ファイルです。 `.zip` も選択可能です。
- 読み込み・解凍・レース抽出はブラウザ内のWeb Workerで処理。サーバーへファイルを送信しません。
- 複数ファイルの読み込みに対応。重複するレースIDは後から読み込んだ方で更新されます。
- 2026年10月26日の実ファイルで **34レース・385頭の読み込み、馬の選択・3頭比較への追加・推し馬設定・仮想レース開始** をブラウザで検証済み。
- スナップショットや指数の欠損項目は架空値で補完しません。
- ブラウザ内に取り込んだファイルはページの再読み込みでクリアされます。ファイルは端末内に残ります。

## 注意

- 仮想レースのゴール順はゲーム演出であり、実際の勝敗予想や回収率を示すものではありません。
- 馬の毛色・ドット絵ポーズは演出です。競馬AIの正式スコア・順位・印は変更しません。
- GitHub Pagesと標準GitHub Actionsを使用。公開リポジトリで無料利用できる範囲のみで運用します。外部有料APIは使いません。
- 他の競馬AIダッシュボードや「FORDAYS カラダチェック」とは独立したリポジトリです。
