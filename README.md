# PIXEL PADDOCK 🐎🎮

競馬初心者向けの無料ブラウザゲーム・体験版です。カード図鑑、脚質別ポーズ、3頭比較、推し馬登録、横画面の仮想レースを楽しめます。

## 公開

GitHub Pagesを設定すると **https://sobiito24-a11y.github.io/pixel-paddock/** で公開されます。

リポジトリの **Settings → Pages → Build and deployment → Source: GitHub Actions** を選択してください。GitHub Actionsの `Deploy PIXEL PADDOCK to Pages` が自動デプロイします。

## データとプライバシー

- 最初から含まれる9レース・99頭、馬名、騎手名、指数は**架空のサンプル**です。
- 本物の馬や実際の競馬データはリポジトリ・公開サイトへ同梱しません。
- `.keiba`（ZIP形式）の追加読み込みが可能です。アップロード先のサーバーはなく、**ユーザーのブラウザ内のWeb Workerで処理**します。ZIP内の `snapshot.json` をローカル展開します。
- 実際の競走結果や馬券の予想ではなく、仮想レースの順位はゲーム上の演出です。
- ブラウザによっては大きな `.keiba` の展開に時間がかかります。現行版はファイルサイズ32MBまで・展開後180MBまでを許容します。

## `.keiba` 読み込み

1. 上部の「＋ 手元の .keiba を読み込む」を押します。
2. `.keiba` または `.zip` を選びます（複数可）。
3. 読込が終わると、画面上部に **「〇レース読込 成功」** が出てレース一覧に追加されます。
4. エラー時は上部のメッセージに理由が表示されます。

2026年10月26日：34R/385頭、10月28日：47R/528頭、10月24日：54R/636頭の実データでZIP抽出をテストしました。

## 技術情報

静的な単一HTMLとBlob Web Workerの構成。外部サーバーやアカウント登録なしで利用可能です。GitHub PagesにはHTMLだけを配信させ、ファイル内容はブラウザの外へ送信しません。

競馬AIダッシュボード、FORDAYS カラダチェックとは**別リポジトリ**で開発しています。
